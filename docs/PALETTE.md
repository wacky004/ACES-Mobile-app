# ACES palette

Derived from the ACES poster supplied by the project owner.

| Role | Hex |
|---|---|
| Deep navy / ink | #0B1E33 |
| Hero navy | #153A5B |
| Steel blue | #4F7EA6 |
| Sky | #B9D9EA |
| Pale sky background | #E8F2F8 |
| Paper / cream | #F7F1E5 |
| Coral accent | #C75B4A |
| Circuit cyan | #3E9FBF |
| Light circuit cyan | #8FD7E8 |
| Gold / sand | #D6BE8A |
| Dark background | #071522 |
| Dark surface | #0F2438 |

## Usage

- Navy and steel are the primary brand colors.
- Sky/pale sky are app backgrounds.
- Paper/cream are supporting cards and notes.
- Coral is the error and destructive action color.
- Circuit cyan is the active/progress accent.
- Gold is a warning/highlight accent.
- Green remains the correct/success color.

## Pattern

`lib/widgets/circuit_pattern.dart` draws low-opacity circuit traces and nodes.
It is used on the splash screen and home hero. The poster image itself is not
bundled.
