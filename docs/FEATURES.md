# Features

## Subjects

- IT2205 - Computer Engineering Laws and Discipline
- IT2102 - Embedded Systems
- IT1919 - Robot Dynamics

Each has four terms and 40 items per term: 30 multiple-choice plus 10 modified
True/False.

## Quiz

- Weighted term allocation.
- Practice and exam modes.
- Timed quizzes.
- Flags, bookmarks, and question navigator.
- Fresh-item priority across attempts.
- Shuffled questions and multiple-choice options.
- Retry missed questions.
- True/False correction revealed after answering and in results review.

## Handouts

- Full-text reader in manageable pages/parts.
- Page-by-page navigation, long-page splitting, jump menu, and resume position.
- Search across handouts, sections, terms, and tables.
- Key-term review and flashcards.
- Per-subject reading progress.
- Practice quiz from a handout.

## AI

- Offline Qwen/Gemma models.
- DeepSeek online BYOK provider.
- Optional OpenAI-compatible free/custom provider.
- Multiple saved custom cloud profiles with separate secure API keys.
- Local AI engine on/off switch with automatic RAM unload on cloud.
- Clear active provider/model banner.
- Tutor and PDF chats.
- Automatic PDF excerpts in PDF chats.
- Persistent chat sessions with history.
- Photos, text files, and PDF attachments.
- Thinking/reasoning display for DeepSeek.
- Token usage display.
- JSON draft question generation.

## PDFs

- Import text PDFs or use offline OCR for scanned pages.
- Chat with a PDF using local or cloud AI without re-uploading it.
- Generate draft quizzes and review every item before saving.

## Web

The web build includes quizzes, reader, progress, and subjects. It contains no
AI UI, API keys, or cloud provider calls.
